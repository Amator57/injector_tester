# Тестер та очистник форсунок (ESP32-C3)

## Опис

Пристрій для тестування та очистки автомобільних бензинових форсунок на базі **ESP32-C3 Supermini**.

Плата формує прецизійні керуючі імпульси (апаратний таймер, роздільність 1 мкс), які через **оптоелектронну розв'язку** (оптопар, наприклад PC817) керують електронним ключем (логічний N-канальний MOSFET, наприклад IRLZ44N / IRLB8721), що подає напругу 12 В на форсунку.

Можливості:

* Робота в мережі WiFi у режимах **STA** (домашня мережа) та **AP** (власна точка доступу)
* Веб-інтерфейс з українізацією (жодних програм не потрібно — лише браузер)
* 4 режими роботи:
  * **Пакет імпульсів** — N імпульсів у пакеті, пакети повторюються з заданим періодом
  * **Безперервний** — безперервна послідовність імпульсів до зупинки
  * **Одиничний імпульс** — імпульс заданої довжини (перевірка розпилення "плевка")
  * **Постійно відкрита** — подача 12В без перерв (промивка), з аварійним тайм-аутом
* Налаштування: **довжина імпульсу**, **період**, **кількість імпульсів у пакеті**, **період пакета**
* Лічильники імпульсів та пакетів, час роботи, частота та коефіцієнт заповнення
* Збереження типових параметрів у незалежній пам'яті (Preferences/NVS)
* Захити: аварійний тайм-аут відкритого стану, глобальний автостоп, мінімальна пауза 50 мкс

## 1. Схема апаратного підключення (Pinout)

| Призначення | GPIO ESP32-C3 | Нотатки |
| :--- | :--- | :--- |
| **Вихід на опторозв'язку** | **GPIO 5** | Через резистор 330 Ом на LED оптопари PC817 |
| **Вбудований LED** | **GPIO 8** | Індикація: блимає у режимі AP, світиться під час імпульсу |

### Типова схема силової частини

```
ESP32-C3 GPIO5 ──[330Ω]──►|PC817 LED|── GND (ESP32)

PC817 (транзисторний вихід):
   колектор ── +12 В
   емітер  ── затвор MOSFET (IRLZ44N)
   + резистор 10 кОм між затвором і GND (надійне закриття)

Силова частина:
   +12 В ──► форсунка ──► стік MOSFET
   джерело MOSFET ──► GND (спільний з мінусом БЖ 12 В)
   !ОБОВ'ЯЗКОВО! зворотний діод (демпфер) паралельно форсунці
   (наприклад 1N5408 або SR560, катодом до +12 В)
```

**Важливо:**

* Опторозв'язка гальванічно розділяє плату ESP32 від силової частини 12 В — земля ESP32 та земля 12 В живлення форсунок з'єднуються **тільки** через оптопару (без прямого з'єднання).
* MOSFET обов'язково логічного рівня (IRL..., не IRF...).
* Форсунка — індуктивне навантаження: без демпферного діода проб'ється MOSFET.
* Якщо ваша схема ключа має інверсію сигналу (оптопара закриває MOSFET при HIGH) — увімкніть опцію **"Інвертувати вихід"** у веб-інтерфейсі.
* Живлення форсунок: 12 В / 3–5 А (залежно від кількості форсунок, що тестуються одночасно).

## 2. Перше увімкнення та налаштування WiFi

1. Увімкніть пристрій. Якщо SSID не налаштований, пристрій створює точку доступу:
   * **SSID:** `InjectorTester_Setup`
   * **Пароль:** відсутній
2. Підключіться та відкрийте [http://192.168.4.1](http://192.168.4.1).
3. У картці **Мережа** введіть SSID та пароль вашої WiFi-мережі → **💾 Зберегти**.
4. Пристрій перезавантажиться та підключиться до вашої мережі (IP дивіться в статусі Wi-Fi на сторінці або в роутері).
5. У режимі AP вбудований LED повільно блимає; під час тесту LED відображає імпульси.

## 3. Параметри імпульсів

| Параметр | Діапазон | Опис |
| :--- | :--- | :--- |
| **Довжина імпульсу** | 0.1 – 1000 мс | Час відкритого стану форсунки (типово для бензину 2–20 мс) |
| **Період** | 0.2 – 60000 мс | Період проходження імпульсів. Обмеження: період ≥ довжина імпульсу + 50 мкс |
| **Імпульсів у пакеті** | 0 – 65535 | Кількість періодів у пакеті (0 = без обмежень) |
| **Період пакета** | 0 – 3600000 мс | Період повторення пакетів, відлік від **початку** пакета. 0 = без паузи. Якщо період пакета коротший за тривалість пакета — пауза не застосовується |

**Приклад** (значення за замовчуванням): імпульс 3 мс, період 15 мс (66.7 Гц, заповнення 20%), 50 імпульсів у пакеті, період пакета 1 с → пакет триває 0.75 с, пауза 0.25 с.

### Режими

* **Пакет імпульсів** — імітація "прокрутки" стартером, ультразвукова очистка з паузами.
* **Безперервний** — імітація роботи двигуна на холостих (3 мс / 15 мс ≈ 66 Гц).
* **Одиничний імпульс** — візуальна перевірка факелу розпилення.
* **Постійно відкрита** — промивка форсунки максимальним протоком; обмежена тайм-аутом безпеки (за замовчуванням 60 с).

### Безпека

* **Макс. час відкритого стану** — аварійне вимкнення режиму "очистка" (0 = без обмежень).
* **Автостоп тесту** — автоматична зупинка будь-якого тесту через заданий час (0 = вимкнено).
* Кнопка **■ Стоп** на веб-сторінці миттєво знімає живлення з форсунки.

## 4. REST API

### GET /api/status
Поточний стан (ополюється інтерфейсом кожні 500 мс):
```json
{
  "running": true,
  "state": "pulse",
  "mode": "burst",
  "pulses": 123,
  "bursts": 2,
  "elapsedMs": 4500,
  "params": { "mode": "burst", "pulseMs": 3, "periodMs": 15, "pulses": 50, "burstPeriodMs": 1000 },
  "wifi": { "mode": "STA", "connected": true, "ip": "192.168.1.105", "ssid": "Home", "rssi": -58 }
}
```
`state`: `idle | pulse | gap | burst_wait | hold | done`

### POST /api/start
Запуск тесту (параметри optional — беруться типові):
```json
{ "mode": "burst", "pulseMs": 3, "periodMs": 15, "pulses": 50, "burstPeriodMs": 1000 }
```
`mode`: `single | burst | continuous | hold`. Значення автоматично обмежуються допустимими діапазонами.

### POST /api/stop
Зупинка тесту.

### GET /api/config / POST /api/config
Читання/запис конфігурації (`device`, `network`, `injector`). Якщо надіслано `device`/`network` — пристрій перезавантажується (`{"restart":true}`); зміна лише `injector` — без перезавантаження (`{"restart":false}`).

### POST /api/restart / POST /api/factory
Перезавантаження / заводське скидання.

## 5. Компіляція та завантаження (PlatformIO)

1. Відкрийте папку `injector_tester` у VS Code з плагіном PlatformIO.
2. **Build** (`✓`) — збірка прошивки (плата `esp32-c3-devkitm-1`, SPIFFS).
3. Підключіть ESP32-C3 Supermini по USB → **Upload** (`→`).
4. **Обов'язково**: завантажте файлову систему з веб-інтерфейсом — **Platform → Upload Filesystem Image** (папка `data`).
5. Відкрийте Serial Monitor (115200) для діагностики.

├── src/

│   └── web_manager.h/.cpp# WiFi AP/STA + веб-сервер + REST API
└── data/
    ├── index.html        # веб-інтерфейс
    ├── style.css
